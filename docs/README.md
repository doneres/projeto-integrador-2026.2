# Documentação do Projeto — AXIS (Account eXecution & Inventory Sales system)

## Sobre

Este projeto é um sistema de gestão de força de vendas externa voltado para empresas de pequeno/médio porte. Ele resolve a falta de visibilidade que coordenadores e supervisores têm sobre o trabalho do vendedor em campo — permitindo acompanhar rotas otimizadas, confirmar visitas por check-in via geolocalização, controlar o inventário de materiais de ponto de venda (PDV) e monitorar o cumprimento de metas em tempo real.

O sistema é dividido em duas frentes: um **painel web**, usado pela gestão para cadastrar clientes, montar rotas e acompanhar indicadores; e um **aplicativo mobile**, usado pelo vendedor para executar a rota do dia, fazer check-in nas visitas, atualizar o inventário, registrar prospecções e realizar vendas de reposição.
